      Comment ça marche ?
      • Tout tient dans ce seul fichier HTML (HTML, CSS et JavaScript). Aucun serveur, il suffit de l'ouvrir dans Chrome ou Edge.
      • Le gagnant est choisi au hasard avant l'animation avec le générateur cryptographique du navigateur (crypto.getRandomValues). L'animation ne fait que montrer le résultat, peu importe la méthode.
      • La liste d'employés est incluse dans le fichier. « Mettre à jour avec le fichier Excel » lit le fichier directement dans le navigateur (colonnes Nom Famille, Prénom, Statut, Lieu travail) et la nouvelle liste reste enregistrée dans ce navigateur.
      • Pour le lot, la carte est repérée en cherchant la zone de l'image qui diffère du fond de la page, puis découpée. Les PDF sont lus avec pdf.js.
      • Les effets (roue, boules, feux d'artifice, feuilles…) sont dessinés en canvas HTML5, les confettis avec canvas-confetti et les sons avec Web Audio.
      • Raccourci : barre d'espace ou Entrée pour lancer un tirage.
